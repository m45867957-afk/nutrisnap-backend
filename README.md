# راه‌اندازی بک‌اند NutriSnap

## مرحله ۱ — ساخت حساب Stripe
۱. به [stripe.com](https://stripe.com) برو و ثبت‌نام کن.
۲. از داشبورد، بخش **Products** یک محصول جدید بساز، مثلاً «اشتراک اسکنر تغذیه».
۳. برای همین محصول **دو تا قیمت (Price)** بساز (چون کد از هر دو پشتیبانی می‌کند):
   - **ماهانه: ۶.۹۹ دلار، تکرارشونده**
   - **سالانه: ۴۹.۹۹ دلار، تکرارشونده**
۴. شناسه‌ی هر کدام (چیزی شبیه `price_1AbC...`) را کپی کن:
   - قیمت ماهانه → `STRIPE_PRICE_ID_MONTHLY`
   - قیمت سالانه → `STRIPE_PRICE_ID_YEARLY`

## مرحله ۲ — گرفتن کلیدهای Stripe
از بخش **Developers → API keys**:
- کلید محرمانه (Secret key) را کپی کن → `STRIPE_SECRET_KEY`
(در ابتدا از کلیدهای حالت تست `sk_test_...` استفاده کن، بعد از اطمینان، به حالت واقعی `sk_live_...` برو)

## مرحله ۳ — دیپلوی سرور
سرور (`server.js`) روی [Railway](https://railway.app) دیپلوی می‌شود.

⚠️ **این سرور به Redis نیاز دارد** (برای ذخیره‌ی دائمی وضعیت اشتراک، مصرف رایگان، و کدهای تأیید ایمیل — نه حافظه‌ی موقت داخل کد):
۱. در داشبورد Railway، روی پروژه‌ات کلیک کن → «+ New» → «Database» → «Add Redis»
۲. Railway به‌صورت خودکار یک متغیر `REDIS_URL` می‌سازد و آن را به این سرویس وصل می‌کند — نیازی نیست خودت دستی تنظیمش کنی

بعد از دیپلوی، متغیرهای محیطی زیر را در تنظیمات سرویس (طبق فایل `env.example`) وارد کن:

| متغیر | برای چی استفاده می‌شود |
|---|---|
| `STRIPE_SECRET_KEY` | پرداخت |
| `STRIPE_WEBHOOK_SECRET` | تأیید رویدادهای Stripe (مرحله‌ی بعد) |
| `STRIPE_PRICE_ID_MONTHLY` | قیمت پلن ماهانه |
| `STRIPE_PRICE_ID_YEARLY` | قیمت پلن سالانه |
| `ANTHROPIC_API_KEY` | تحلیل عکس غذا با هوش مصنوعی |
| `USDA_API_KEY` | گرفتن مقادیر تغذیه‌ای رسمی (اختیاری؛ بدونش از `DEMO_KEY` با محدودیت استفاده می‌شود) |
| `ADMIN_SECRET` | فعال/غیرفعال کردن دستی Premium برای تست |
| `RESEND_API_KEY` | ارسال ایمیل کد تأیید هنگام ورود کاربر |
| `RESEND_FROM_EMAIL` | آدرس فرستنده‌ی ایمیل کد تأیید |
| `FRONTEND_URL` | آدرس دقیق فرانت‌اند (برای محدود کردن CORS فقط به همین دامنه) |

## مرحله ۴ — تنظیم Webhook
۱. در داشبورد Stripe، بخش **Developers → Webhooks → Add endpoint**.
۲. آدرس را بگذار: `https://آدرس-سرور-تو/webhook`
۳. رویدادهای زیر را انتخاب کن:
   - `checkout.session.completed`
   - `customer.subscription.updated`
   - `customer.subscription.deleted`
   - `invoice.payment_failed`
۴. کلید امضای webhook (`whsec_...`) را کپی کن → `STRIPE_WEBHOOK_SECRET`

## مرحله ۵ — کلید هوش مصنوعی
از [console.anthropic.com](https://console.anthropic.com) یک کلید API بساز و به‌عنوان `ANTHROPIC_API_KEY` اضافه کن. این کلید برای تحلیل عکس خوراکی‌ها استفاده می‌شود.

*(در حال بررسی: جایگزینی با یک مدل ارزان‌تر مثل GPT-4o mini برای کاهش هزینه در مقیاس بین‌المللی.)*

## مرحله ۶ — ورود کاربر با ایمیل (کد تأیید)
به‌جای شناسه‌ی تصادفی مرورگر، کاربر باید ایمیلش را با یک کد ۶ رقمی تأیید کند. این کار با [Resend](https://resend.com) انجام می‌شود:
۱. یک حساب Resend بساز و یک API Key بگیر → `RESEND_API_KEY`
۲. تا وقتی دامنه‌ی اختصاصی خودت را در Resend تأیید نکرده‌ای، از آدرس تستی استفاده کن: `RESEND_FROM_EMAIL=NutriSnap <onboarding@resend.dev>`
   - ⚠️ با این آدرس تستی، ایمیل‌ها معمولاً در Gmail به پوشه‌ی اسپم می‌روند — برای کاربران واقعی، تأیید یک دامنه‌ی اختصاصی در Resend ضروری است.
   - اگر `RESEND_API_KEY` تنظیم نشود، کد تأیید فقط در لاگ سرور چاپ می‌شود (فقط مناسب تست، نه تولید واقعی).

## مرحله ۷ — اتصال فرانت‌اند
فایل `App.jsx` از قبل به این سرور وصل شده — فقط کافیه در بالای آن فایل، مقدار `BACKEND_URL` را با آدرس واقعی سروری که دیپلوی کردی جایگزین کنی. همچنین مطمئن شو `FRONTEND_URL` در بک‌اند دقیقاً با آدرس دیپلوی‌شده‌ی فرانت‌اند یکی است (وگرنه بک‌اند به‌خاطر محدودیت CORS، درخواست‌های فرانت‌اند را رد می‌کند).

## مرحله ۸ — تست ادمین (فعال‌سازی دستی Premium)
اندپوینت‌های `/admin/grant-premium` و `/admin/revoke-premium` با متد **POST** کار می‌کنند (نه GET)، چون رمز ادمین باید در بدنه‌ی درخواست باشد، نه در آدرس URL:
```
POST /admin/grant-premium
Body: { "userId": "...", "secret": "مقدار ADMIN_SECRET" }
```

## نکته درباره‌ی نسخه‌ی موبایل (اپ‌استور)
اگر اپ را با React Native یا Capacitor به اپ نصب‌شدنی تبدیل کنی، اپل و گوگل معمولاً برای محتوای دیجیتال داخل اپ (In-App Purchase) الزام می‌کنند از سیستم پرداخت خودشان استفاده کنی، نه Stripe مستقیم — در غیر این صورت ممکن است اپ رد شود. برای نسخه‌ی وب (PWA) محدودیتی نیست و Stripe به‌طور کامل کار می‌کند.
